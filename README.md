### `01` — About Me

I'm a Full-Stack Software Engineer interested in building reliable, scalable applications and exploring how AI can make software more useful.

I work across the **JavaScript and TypeScript ecosystem**, from designing backend APIs and database architectures to building frontend experiences and deploying applications to the cloud.

My approach is simple: understand the problem, design the system, write maintainable code, and keep improving.

- **Full-stack development** — End-to-end web applications and REST APIs.
- **Backend engineering** — Authentication, authorization, database design, and clean architecture.
- **AI engineering** — LLM integrations, RAG pipelines, and agentic workflows.
- **Infrastructure** — Cloud deployment, Linux servers, and reverse proxies.
