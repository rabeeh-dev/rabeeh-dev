## `01` / About Me

I'm a Full-Stack Software Engineer passionate about building reliable applications, designing maintainable backend systems, and exploring AI-powered solutions.

I work primarily with the **JavaScript and TypeScript ecosystem**, building across the stack — from frontend experiences and REST APIs to database architecture, authentication, and cloud deployment.

- **Backend Engineering** — API design, authentication, authorization, and database architecture.
- **Full-Stack Development** — End-to-end applications with React, Node.js, Express, and MongoDB.
- **AI Engineering** — LLM integrations, RAG pipelines, and agentic workflows.
- **System Design** — Clean architecture, SOLID principles, design patterns, and scalability.
- **Continuous Learning** — Data structures, algorithms, and practical software engineering.
